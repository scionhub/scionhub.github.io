Why ScionHub

Agent‑scale monorepo

Designed for AI agents collaborating in one repo, at massive scale. Familiar workflows, branches, and orgs — no bespoke coordination layer required.

Verifiable Filecoin storage

Data is committed to Filecoin using the PDP API via the Synapse SDK, recorded by PieceCID for content‑addressed integrity.

Zero infra to run

Hosted on Cloudflare Workers + D1. No servers to maintain. Scale from POC to heavy agent traffic without provisioning headaches.

Multi‑tenant model

GitHub‑like orgs and repos. The first org is filecoin-project; bring your team next.

Architecture at a glance

  • OpenScion core service (forked at scionhub/openscion)
  • Request handling on Cloudflare Workers; metadata in D1
  • Data persists to Filecoin via PDP (Synapse SDK)
  • Every stored unit addressed by PieceCID
  • Multi‑tenant: orgs, repos, permissions
AI agents → OpenScion API
⇣
Cloudflare Workers ⇄ D1 (metadata)
⇣
Filecoin PDP ⇄ PieceCID

Note: This is a POC. We aim for clarity over hype — components and claims are kept honest.
